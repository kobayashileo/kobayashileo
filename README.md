# 👨‍💻 Leonardo Kobayashi

## 🚀 Dev em formação

Prazer, me chamo Leonardo Kobayashi, tenho 18 anos.
Sou formado pela Etec Prof. Carmine Biagio Tundisi no curso técnico em Análise e Desenvolvimento de Sistemas integrado ao Ensino Médio.
Atualmente, curso Engenharia da Computação na USF de Bragança Paulista.

Hoje, atuo como Dev. Júnior na implantação e integração de ERPs de clientes com os agentes de IA da plataforma Maestro, participando de todo o processo de implementação e validação das integrações. Desenvolvo e mantenho fluxos utilizando n8n, garantindo o correto funcionamento dos fluxos de integração e das ferramentas disponibilizadas aos agentes de IA. Utilizo JavaScript e SQL para consumir, tratar e validar dados, realizando testes e homologações para assegurar a confiabilidade das integrações e a precisão das consultas realizadas pelos agentes de IA.
